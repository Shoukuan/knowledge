# 驱动模型

驱动模型是 Linux 内核与硬件交互的组织骨架，当前资料覆盖平台设备、设备模型对象和常用驱动 API。

## 核心问题

- platform bus 在驱动框架中的定位是什么
- kobject、kset、ktype 如何组织设备模型
- 驱动 API 与设备树如何协同完成设备初始化
