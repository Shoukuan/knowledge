# SPI 总线

SPI（Serial Peripheral Interface）是全双工同步串行总线，主从架构。

## 信号线

| 信号 | 方向 | 作用 |
|------|------|------|
| SCK | M→S | 时钟 |
| MOSI | M→S | 主机输出/从机输入 |
| MISO | S→M | 主机输入/从机输出 |
| CS/SS | M→S | 片选（低有效），每从机独立 |

## 四种模式（CPOL + CPHA）

| 模式 | CPOL | CPHA | 空闲时钟 | 采样沿 |
|------|------|------|----------|--------|
| 0 | 0 | 0 | 低 | 上升沿 |
| 1 | 0 | 1 | 低 | 下降沿 |
| 2 | 1 | 0 | 高 | 下降沿 |
| 3 | 1 | 1 | 高 | 上升沿 |

## 典型时序（模式 0）

**写**：CS↓ → 循环 8 次（设 MOSI → SCK↑ → 左移 → SCK↓）→ CS↑

**读**：CS↓ → 循环 8 次（SCK↑ → 采样 MISO → SCK↓）→ CS↑

## 寄存器操作模式

- **写寄存器**：CS↓ → 发命令字节|地址 → 发数据 → CS↑
- **读寄存器**：CS↓ → 发命令字节|地址 → 读数据 → CS↑

## 多从机拓扑

1. **独立 CS**：每个从机一根线，主机按需拉低
2. **菊花链**：MOSI 串联，数据依次通过各从机

## 优缺点

**优点**：全双工、无寻址开销、协议简单、速率高（可达数十 Mbps）

**缺点**：无应答/流控机制、线数随从机增加（3+n）、仅短距离
