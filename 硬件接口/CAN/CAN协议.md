# CAN 协议

CAN（Controller Area Network）是汽车和工业控制领域广泛使用的差分串行总线。

## 物理层

- **两根差分线**：CAN_H 和 CAN_L
- **四个核心组件**：控制器 → 收发器 → 终端电阻 → 双绞线
- **终端电阻**：防止信号反射，通常在总线两端各接 120Ω

## 帧类型

| 帧类型 | 用途 |
|--------|------|
| 数据帧 | 发送数据（0-8 字节） |
| 远程帧 | 请求其他节点发送数据 |
| 错误帧 | 检测到错误时发出 |
| 过载帧 | 请求额外延迟 |
| 帧间隔 | 帧与帧之间分隔 |

## 数据帧结构

7 个段：帧起始 → 仲裁段 → 控制段 → 数据段 → CRC 段 → ACK 段 → 帧结束

### 标准帧 vs 扩展帧

| | 标准帧 (2.0A) | 扩展帧 (2.0B) |
|------|------|------|
| ID 长度 | 11 位 | 29 位 |
| 帧 ID 范围 | 0-2047 | 0-536870911 |

## 仲裁机制

- **显性位**（逻辑 0）覆盖**隐性位**（逻辑 1）
- 发送时回读总线电平，不一致则失去仲裁，立即退出发送
- **ID 越小，优先级越高**
- 标准帧优先级高于扩展帧（因 IDE 位差异）

## 关键特性

- 短帧结构（0-8 字节数据），实时性好
- 逐位非破坏性仲裁
- 多主总线，任意节点可随时发送
- CRC 校验 + 多种错误检测
- 严重错误时节点自动离线（bus-off）
